# T06.4 — Asociar los datos del cliente con el pedido

| Elemento | Descripción |

### Historia de usuario

Como cliente, quiero registrar mi nombre y número de WhatsApp al realizar un pedido anticipado, para que el establecimiento pueda identificar mi compra y asociarla correctamente con mis datos.

## 2. Objetivo

Documentar la relación entre los datos del cliente y los pedidos registrados en AlInstant, comprobando cómo se vincula la información del nombre y número de WhatsApp con cada compra realizada.

## 3. Descripción de la implementación

El proyecto utiliza PostgreSQL como sistema de gestión de base de datos y Prisma como herramienta para definir los modelos y acceder a la información desde el backend.

La asociación se establece mediante dos entidades principales:

| Entidad | Descripción |
|---|---|
| `Customer` | Almacena el identificador, nombre y teléfono del cliente. |
| `Order` | Almacena los datos del pedido y la referencia al cliente asociado. |

### Relación entre las entidades

El modelo `Customer` contiene una relación con los pedidos mediante `orders Order[]`.

Por su parte, `Order` utiliza `customerId` como clave foránea que referencia a `Customer.id`.

Esto establece una relación de **uno a muchos (1:N)**, donde un cliente puede realizar varios pedidos, pero cada pedido pertenece a un cliente.

Adicionalmente, el modelo `Order` conserva los campos `customerName` y `customerPhone`, permitiendo mantener los datos de identificación utilizados al momento de realizar la compra.

## 4. Modelo de base de datos

La relación entre ambas entidades se encuentra definida en el archivo `prisma/schema.prisma`.

### Modelo Customer

```prisma
model Customer {
  id        String   @id @default(cuid())
  name      String   @default("")
  phone     String   @default("")
  createdAt DateTime @default(now())
  sessions  Session[]
  orders    Order[]
}
```

### Relación desde el modelo Order

```prisma
customerId    String
customerName  String
customerPhone String

customer Customer @relation(
  fields: [customerId],
  references: [id]
)
```

El campo `customerId` permite identificar al cliente al que pertenece cada pedido.
