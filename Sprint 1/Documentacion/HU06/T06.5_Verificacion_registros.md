# T06.5 — Verificar escenarios de registro correcto e incorrecto

## 1. Información general

| Elemento | Descripción |
|---|---|
| Proyecto | AllInstant — ALESAR |
| Sprint | Sprint 01 |
| Historia de usuario | HU-06 — Registrar datos del cliente |
| Tarea | T06.5 — Verificar escenarios de registro correcto e incorrecto |
| Estado | Evidencias funcionales incorporadas; verificación parcial |

### Historia de usuario

Como cliente, quiero registrar mi nombre y número de WhatsApp al realizar un pedido anticipado, para que el establecimiento pueda identificar mi compra y asociarla correctamente con mis datos.

## 2. Objetivo

Verificar el funcionamiento del registro de datos del cliente durante el proceso de compra anticipada en AllInstant, considerando el ingreso de información válida e inválida.

Asimismo, comprobar que el sistema permita continuar con el pedido cuando los datos cumplen las condiciones establecidas y rechace aquellos que no cumplen las reglas de validación.

## 3. Condiciones para realizar las pruebas

Para realizar las pruebas funcionales se consideran las siguientes condiciones:

- La aplicación AllInstant debe encontrarse iniciada.
- Se debe seleccionar una sede.
- El carrito debe contener al menos un producto.
- Se debe seleccionar un horario de recojo.
- Se deben utilizar datos ficticios para el registro.
- El sistema debe permitir acceder al formulario de nombre y WhatsApp.

## 4. Casos de prueba

| ID | Escenario | Resultado esperado | Evidencia |
|---|---|---|---|
| CP-06-01 | Registrar nombre y WhatsApp válidos | Permite continuar con el pedido | Evidencias 1 y 2 |
| CP-06-02 | Intentar continuar con el nombre vacío | Impide avanzar | Documentado en T06.3 |
| CP-06-03 | Ingresar WhatsApp con formato inválido | Rechaza los datos | Documentado en T06.3 |
| CP-06-04 | Completar el proceso de compra | Genera un código de pedido | Evidencia 4 |

Los casos con datos incorrectos se encuentran documentados en T06.3, por lo que no es necesario repetir las mismas capturas.

## 6. Resultado de la tarea

Se recopilaron evidencias visuales del proceso de registro de los datos del cliente, la revisión del pedido y la generación de su código de identificación.

Asimismo, se tomaron como referencia los escenarios de datos incorrectos documentados en la tarea T06.3, correspondientes a la validación del nombre vacío y del número de WhatsApp inválido.

Las evidencias permiten documentar el funcionamiento observable del proceso de compra. La verificación directa de los registros en PostgreSQL se mantiene como una comprobación adicional pendiente.

## 7. Conclusión

La tarea permitió documentar diferentes etapas del registro del cliente y su participación en el proceso de compra anticipada de AllInstant.

Las capturas recopiladas muestran el ingreso de datos, la revisión del pedido y la generación de su código de identificación.

En conjunto con las validaciones documentadas en T06.3 y la relación cliente-pedido descrita en T06.4, estas evidencias permiten sustentar el desarrollo de la HU-06 y facilitan su posterior revisión por parte del equipo.
