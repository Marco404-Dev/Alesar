# T06.2 — Diseñar el formulario de nombre y WhatsApp

## 1. Información general

| Elemento | Descripción |
|---|---|
| Proyecto | AllInstant — ALESAR |
| Sprint | Sprint 01 |
| Historia de usuario | HU-06 — Registrar datos del cliente |
| Tarea | T06.2 — Diseñar el formulario de nombre y WhatsApp |
| Estado | Diseño documentado; pruebas funcionales pendientes |

### Historia de usuario

Como cliente, quiero registrar mi nombre y número de WhatsApp al realizar un pedido anticipado, para que el establecimiento pueda identificar mi compra y asociarla correctamente con mis datos.

## 2. Objetivo

Diseñar y documentar una interfaz sencilla, intuitiva y responsive que permita al cliente ingresar su nombre y número de WhatsApp durante el proceso de compra anticipada en AllInstant.

## 3. Diseño e implementación

El formulario se encuentra implementado en `src/customer.tsx`, mediante el componente `CustomerForm`, utilizando React y TypeScript.

La interfaz está diseñada para adaptarse a computadoras y dispositivos móviles, manteniendo la accesibilidad de los campos y facilitando el ingreso de información.

### Elementos del formulario

| Elemento | Función |
|---|---|
| Nombre | Permite identificar al cliente. |
| Número de WhatsApp | Permite ingresar el número de contacto. |
| Prefijo +51 | Identifica el código telefónico de Perú. |
| Campos obligatorios (*) | Indican que ambos datos son necesarios. |
| Botón Continuar | Permite avanzar cuando los datos cumplen las validaciones. |
| Mensajes de error | Informan cuando existe algún problema con los datos ingresados. |

### Flujo de navegación

El formulario forma parte del proceso de compra:

**Carrito de compras → Selección de horario → Datos del cliente → Revisión del pedido**

## 4. Criterios de aceptación
