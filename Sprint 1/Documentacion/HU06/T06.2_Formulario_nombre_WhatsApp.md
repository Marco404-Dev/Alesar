## 2. Objetivo

Describir la interfaz que permite ingresar nombre y número de WhatsApp durante el proceso de compra anticipada.

## 3. Diseño e implementación

El formulario se encuentra en `src/customer.tsx` (`CustomerForm`) y utiliza estilos del proyecto para pantallas de escritorio y móvil.

| Elemento | Función |
|---|---|
| Nombre | Identificar al cliente |
| Número de WhatsApp | Registrar el teléfono de contacto |
| Indicador obligatorio | Avisar que los datos son requeridos |
| Continuar | Solicitar el guardado y avanzar cuando la validación lo permita |
| Mensajes de error | Informar un problema con los datos o el guardado |

Flujo esperado: carrito → horario de recojo → datos del cliente → revisión del pedido.

## 4. Criterios de aceptación

- [ ] Se muestran los campos Nombre y WhatsApp con sus etiquetas.
- [ ] La interfaz se adapta a móvil y escritorio.
- [ ] El usuario puede editar ambos campos.
- [ ] Si se aceptan los datos, se accede a la revisión del pedido.
