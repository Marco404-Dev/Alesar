
# T10.3 — Diseño de la interfaz de selección del medio de pago

### Historia de usuario

Como cliente, quiero pagar mi pedido mediante Yape o tarjeta desde la página web, para completar mi compra antes de llegar al establecimiento.

## 2. Objetivo

Diseñar la interfaz de pago de AllInstant para que el cliente pueda revisar el monto total de su compra y seleccionar entre Yape o tarjeta antes de continuar con la operación.

Para esta tarea se toman como referencia las reglas de negocio definidas en la T10.1 y el diagrama de actividades desarrollado en la T10.2.

El diseño busca que el proceso de pago sea sencillo y que el cliente pueda identificar claramente las opciones disponibles.

## 3. Diseño de la interfaz de pago

La pantalla se organiza en diferentes secciones para mostrar la información del pedido y permitir la selección del medio de pago.

### 3.1. Resumen del pedido

La interfaz contempla un resumen de la compra antes de realizar el pago.

Se consideran los siguientes elementos:

- Sede seleccionada por el cliente.
- Productos agregados al carrito.
- Cantidad de cada producto.
- Precio unitario y subtotal.
- Monto total del pedido.

El monto total deberá actualizarse de acuerdo con los productos y cantidades seleccionadas.

### 3.2. Selección del medio de pago

Se consideran dos opciones de pago:

**Yape**

El cliente podrá seleccionar Yape como medio de pago. Al elegir esta opción, el sistema deberá mostrar las indicaciones necesarias para continuar con la operación.

**Tarjeta**

El cliente podrá seleccionar tarjeta como medio de pago. La interfaz deberá permitir continuar con el formulario o servicio correspondiente.

En ambos casos, la selección del medio de pago no confirma automáticamente la compra. El sistema deberá recibir un resultado aprobado antes de confirmar el pedido.

### 3.3. Acciones de la interfaz

La pantalla contará con las siguientes acciones:

| Elemento | Función |
|---|---|
| Resumen de compra | Muestra los productos y el monto total. |
| Opción Yape | Permite seleccionar Yape como medio de pago. |
| Opción Tarjeta | Permite seleccionar el pago mediante tarjeta. |
| Volver al resumen | Permite regresar a la información del pedido. |
| Continuar con el pago | Permite iniciar el proceso con el medio seleccionado. |

El botón para continuar deberá permanecer deshabilitado mientras el cliente no seleccione un medio de pago.

### 3.4. Adaptación responsive

El diseño deberá adaptarse a celulares, tablets y computadoras, siguiendo los estilos generales del proyecto AllInstant.

En dispositivos móviles, los elementos se organizarán principalmente en una columna para facilitar su visualización.

En pantallas más grandes, el resumen del pedido y las opciones de pago podrán distribuirse aprovechando el espacio disponible.
