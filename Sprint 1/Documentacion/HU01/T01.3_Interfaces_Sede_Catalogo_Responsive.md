# T01.3 — Interfaces de selección de sede y catálogo de productos

**Proyecto:** AlInstant — ALESAR  
**Sprint:** 1  
**Historia de usuario:** HU-01 — Realizar un pedido anticipado para recojo  
**Estado:** Implementado y probado localmente; integración a `main` según aprobación del equipo.

## Objetivo

Implementar las interfaces de selección de sede y catálogo de productos, tomando como referencia el prototipo de Figma y adaptándolas a celulares, tablets y computadoras.

## Desarrollo realizado

- **Selección de sede:** el cliente puede elegir San Martín de Porres o La Molina y continuar al catálogo.
- **Catálogo:** se muestran cinco productos con fotografía, descripción y precio.
- **Cantidades:** se puede agregar un producto y aumentar o disminuir su cantidad.
- **Total del carrito:** se actualizan automáticamente las unidades y el monto conforme se seleccionan productos.
- **Diseño responsive:** una columna de productos en celular, dos en tablet y tres en computadora.

## Tecnologías utilizadas

React, TypeScript, Vite y CSS. Para esta tarea se utilizaron datos locales; no requiere conexión con backend ni base de datos.

## Archivos principales

- `frontend/src/App.tsx`: interfaces y lógica de selección y cantidades.
- `frontend/src/App.css` e `index.css`: estilos y adaptación responsive.
- `frontend/public/images/`: fotografías del catálogo.
