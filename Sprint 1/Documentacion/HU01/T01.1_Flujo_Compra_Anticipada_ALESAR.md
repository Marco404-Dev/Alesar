# T01.1 — Flujo de compra anticipada

**Proyecto:** ALESAR — AlInstant  
**Sprint:** 1  
**Historia de usuario:** HU-01 — Realizar un pedido anticipado para recojo  
**Tarea:** T01.1 — Documentar el flujo de compra anticipada  
**Estimación:** 2 horas

## 1. Objetivo

Documentar el proceso mediante el cual un cliente realiza un pedido anticipado desde su celular, seleccionando una sede, agregando productos al carrito, revisando su compra y continuando al proceso de pago.

## 2. Descripción de la historia de usuario

**Como** cliente de ALESAR,  
**quiero** realizar mi pedido desde mi celular antes de llegar al establecimiento,  
**para** evitar la cola de toma de pedido y acercarme principalmente a recoger mi comida.

## 3. Alcance

El flujo comprende desde el inicio de la compra hasta la redirección al proceso de pago. La ejecución del pago y su aprobación o rechazo pertenecen a otra historia de usuario, por lo que no se incluyen en esta tarea.

**Actor principal:** Cliente de ALESAR.

**Sedes disponibles:** San Martín de Porres y La Molina.

## 4. Flujo principal

| Paso | Acción | Resultado esperado |
|---|---|---|
| 1 | El cliente inicia el proceso de compra. | El sistema solicita las sedes disponibles. |
| 2 | El sistema muestra las sedes San Martín de Porres y La Molina. | El cliente puede elegir la sede de recojo. |
| 3 | El cliente selecciona una sede. | El sistema registra la sede elegida para la compra en curso. |
| 4 | El sistema obtiene y muestra el catálogo de la sede seleccionada. | El cliente visualiza los productos del catálogo. |
| 5 | El cliente agrega productos al carrito e indica sus cantidades. | El sistema actualiza el contenido del carrito. |
| 6 | Si lo desea, el cliente modifica las cantidades antes de confirmar. | El sistema actualiza las cantidades del carrito. |
| 7 | El cliente selecciona la opción para continuar con el pedido. | El sistema obtiene el resumen de compra. |
| 8 | El sistema muestra los productos seleccionados, sus cantidades y el monto total. | El cliente puede revisar la información de su pedido. |
| 9 | El cliente confirma que desea continuar con la compra. | El sistema conserva la información del pedido. |
| 10 | El sistema dirige al cliente al proceso de pago. | El flujo de HU-01 finaliza, sin dar por aprobado el pago. |

## 5. Comportamientos contemplados

- **Agregar varios productos:** el cliente puede repetir la acción de agregar productos al carrito.
- **Modificar cantidades:** antes de confirmar, el cliente puede ajustar las cantidades seleccionadas.
- **Revisar el pedido:** el cliente visualiza productos, cantidades y monto total antes de continuar.

## 6. Criterios de aceptación relacionados

| Criterio | Verificación dentro del flujo |
|---|---|
| CA1 — Selección de sede | Se permite elegir San Martín de Porres o La Molina (pasos 2 y 3). |
| CA2 — Selección de productos | Se pueden agregar productos y modificar cantidades antes de confirmar (pasos 4 a 6). |
| CA3 — Revisión del pedido | Se muestra el resumen con productos, cantidades y monto total (pasos 7 y 8). |
| CA4 — Confirmación del pedido | Se conserva la información de la compra y se dirige al pago (pasos 9 y 10). |

## 7. Resultado esperado

El cliente completa la selección y revisión de su pedido anticipado, y llega al proceso de pago con la sede, los productos, las cantidades y el monto total de la compra conservados. **Esto no significa que el pago ya haya sido realizado ni aprobado.**
