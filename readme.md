ALESAR - Sistema de Gestión de Pedidos

Proyecto desarrollado para el curso de Ingeniería de Software de la Universidad Peruana Cayetano Heredia (UPCH).

Descripción

Sistema web para gestionar pedidos anticipados de la cafetería ALESAR, facilitando la atención a los estudiantes y la organización de los pedidos.

Gestión de tareas

Las actividades del equipo se organizan mediante GitHub Projects, utilizando un tablero Kanban:

- To Do: tareas pendientes.
- WIP: tareas en desarrollo.
- Done: tareas finalizadas.

Herramientas

- GitHub y GitHub Projects
- Figma
- UML
